# 三界设定

## 1 总纲：三界不是善恶阵营，而是三层意识体的结合

建议写法：

天、人、地三界并立，但不是三个国家，也不是善恶阵营，而是不同概念的不同存在形式。
天界是信息 / 概念 层；人界是物质 / 能量层；地界是本能 / 潜意识 / 集体无意识层。
三界都有自己的社会、语言、意识形态，但天界通过“神职体系”和“概念操作技术”维持三界结构稳定。
所有存在皆出于本能行动，没有绝对的正反派。冲突来自本能之间的结构性碰撞，而非善恶对立。

核心要点：
- 三界是分层本体论，不是上下楼。
- 天界管“意义”，人界管“物质”，地界管“本能”。
- 无绝对正反派，恶是本能碰撞的副作用。
- 天界并非“统治三界”，而是维持结构稳定。

## 2.三界主题

### 2.1 天界

天界为“神明”意识体的集结处，由主神**哈拉利**主持。天界并无具体的物理位置，意识体的结合可以存在于任何位置。

建议写法：
- 天界的意识体被称为“神明”，但并无实体。这个称呼只是为了创作方便而给出的代称。
- 在天界点出影响实体世界的“科技树”之前，它们只是一些“幽灵”。
- 科技树不是机械技术，而是概念操作技术：命名、符号、仪式、音乐、信仰网络。
- 神明不是“分管人类领域”的官员，而是存在本身的不同面向。人类概念只是这些面向的低维投影。
- 例如：不是“音乐之神掌管音乐”，而是“共鸣本能被人类感知为音乐”。
- 天界分权不是部门分工，而是本能之间的张力矩阵。已知本能包括：结构、共鸣、边界、依附等。

核心要点：
- 天界意识体无实体，原本是“幽灵”。
- 科技树 = 概念操作技术，让天界能通过接口影响实体世界。
- 神明 = 抽象本能，不是人类职业。
- 人类概念是低维投影，是结果，不是原因。
- 分权 = 张力矩阵，不是部门分工。

历史优先：天界本能张力先于人类诞生。

人界对天界相关概念的对照举例

|人类命名|天界本质|实际功能|人类投影|
|-------|-------|-------|-------|
|主神|结构本能|维持三界可预测稳定|律法、王权、传统、物理定律|
|音乐与歌剧之神茜塔莉娅|共鸣本能|让分离结构产生共振|音乐、歌剧、共情、通信|
|纯洁之神维斯塔|边界本能|维持系统纯粹性，排斥异质|礼仪、审美、道德、免疫系统|

### 2.2 人界

人界首府为**卡斯德莫**，是白月离生活并与茜塔莉娅**首次共鸣**的地方。

建议写法：
- 人界是人类生活的界地，设定原型为21世纪中的现实世界。
- 大多数人不知道三界存在，因为天界维护着一层“认知帷幕”。
- 认知帷幕让人界把异常解释为巧合、科学未知、心理现象。
- 神明不能直接违反物理定律，只能通过接口干预：概率偏转、代行者、仪式、艺术作品、梦境。
- 信仰、集体情感、艺术共鸣是天界干预人界的“燃料”。
- 卡斯德莫是人界首府，也是艺术之都，帷幕最薄。音乐、歌剧、戏剧在这里能直接沟通天界。
- 科学无法证实三界，因为神迹不可重复、认知被过滤、影响发生在“意义层”而非“物理层”。

核心要点：
- 人界是21世纪现实，不是异世界。
- 认知帷幕让人界自动忽略或合理化异常。
- 天界影响人界有接口、有代价、有盲区。
- 卡斯德莫是艺术之都，帷幕最薄，三界交汇点。
- 科学只能看到“如何发生”，看不到“为何发生”。

### 2.3 地界

地界是简单意识体的集结处，渴望光明，渴望被认可。

建议写法：
- 地界为人界之下的界地，生活着各种简单意识体。
- 地界是集体潜意识、原始本能、被遗忘之物的归宿。
- 简单意识体可以进化：从本能到自我，从自我到觉醒。
- 它们渴望被看见、被命名、被赋予意义。
- 当天界用艺术控制人界时，地界可能也在偷听歌剧，逐渐产生自我意识。
- 地界不是背景板，而是第三股力量：被压迫者的觉醒。
- 它们渴望突破边界，获得意义。天界需要地界作为“底层”维持结构，地界需要突破底层来获得存在感。这是结构性压迫，而非道德上的恶。

核心要点：
- 地界 = 集体潜意识、原始本能、被遗忘之物。
- 简单意识体可进化、可觉醒。
- 渴望被命名、被看见。
- 第三势力，不是恶魔。
- 与天界是结构性冲突，不是善恶对立。
