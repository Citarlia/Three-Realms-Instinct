# 三界交互法则

三界是三个不同的实在层级，各自有规则。该世界观不是SF世界，主题是玄幻，因此不要“用科学解释魔法”。不要使用常规的SF的物理干预、大规模显化等俗套内容。天界是“信息层”，人界是“物质层”。信息熵的改变引起物质世界的演化。


三界各自有规则，交互有接口、有代价、有盲区。

天界是意识体，人界是物质世界，地界是简单意识体。

|层级|本质|规则|人界科学能否直接观测|
|---|---|---|---|
|天界|信息/意识/概念层|权柄、信仰、命名、共鸣|否|
|人界|物质/能量层|物理定律|是|
|地界|本能/潜意识/集体无意识层|渴望被认可的本能|间接|

## 天界

神明无实体，不能直接违反物理定律。它们只能通过接口干预：
例如，可以通过共鸣场与某些具备特殊能力的人群相共鸣进行简单的交流。但一般情况下，这种共鸣力量及其微弱，大部分人会直接将其作为“幻觉”、“走神”等直接忽略。具体可以参考茜塔莉娅与白月离的交流方式。

1. 认知帷幕
- 天界维护一层集体认知过滤，让人界把异常解释为巧合、心理现象、科学未知。
- 只有特定人群能穿透：艺术家、疯子、信徒、濒死体验者、代行者。
- 卡斯德莫作为艺术之都，帷幕最薄，所以茜塔莉娅在这里能显现。

2. 概率偏转
- 神明不能凭空造物，但能在概率云中选择一个可能性。比如祈祷治病：不是神直接修复细胞，而是让某个免疫反应被触发。
- 科学只能看到“自愈”或“巧合”等，无法重复实验，因此人界无法直接观测到天界。

3. 代行者与仪式
- 神明必须通过代行者、圣物、圣地、艺术作品、梦境传递影响。
- 代行者有自由意志，可能误读、背叛、放大或扭曲神意。
- 仪式是“协议”，更精确，效果更强，但代价也更大。

4. 信仰与情感作为能量
- 信仰、集体情感、艺术共鸣是天界干预人界的“燃料”。
- 音乐与歌剧是茜塔莉娅的权柄，因为艺术天然跨越物质与意识，是天然接口。
- 一场歌剧可以改变一座城市的气氛，进而改变历史走向。

5. 代价与不可逆
- 每次干预都有代价：神明失去记忆、权柄磨损、代行者折寿、地界反噬等。
- 这样避免“神明万能”，也解释为什么天界不直接统治人界。

## 人界

1. 人界即为现实世界的人类社会，与一般人类的认知并无过多差异。
2. 人界以现实的物理定律为规则运行，是物质主导的世界。人界的所有现象本质上都是物质演化。
3. 天界对人界的影响主要通过改变信息熵来实现，信息的改变指导物质的演变。
4. 天界对人界的影响往往无法被人类的科学理论所解释。因为科学对于现象的解释依赖于规律，而这种影响无法符合人类的已知所有的物理规律。因此这种影响会被解释为“幻觉”、“梦境”、“濒死体验”、“臆想”等
5. 天界有时也会以显现的方式影响人界。人界中的圣地、圣物等都可以成为神明显现的地方。这些地区或物品周围往往具有强烈的信息场，神明在此显现出的迹象被人类称为“神迹”

## 地界

1. 天界需要“命名”来维持结构，人界需要“遗忘”来维持稳定，而地界恰恰是未被命名之物和被遗忘之物的归宿。地界渴望被看见，但它的被看见会同时威胁天界结构和人界稳定。
2. 地界无法直接出现在人界，因为人界的物质规则对它来说是“高维屏障”。但它可以通过意识层的裂缝渗入。
3. 地界对天界的反噬是天界与地界的核心矛盾。地界意识体的渗透可能产生“伪神”等不可控因素，天界视之为重大的不稳定因素，必须予以遏制。
4. 堕落神 / 野神：这些可能是天界意识体与地界交互后产生的变异。它们不再是纯粹的结构或共鸣，而是混合体——既渴望结构，又渴望突破。它们是天界最恐惧的存在。

## 具体交互机制的设计

这里举一些例子作为参考：

1. 梦境通道

|维度|规则|
|---|---|
|触发|人界意识体进入深度睡眠或极端情绪|
|表现|地界意识体以象征、情绪、画面形式出现|
|限制|无法传递精确语言，只能传递感受|
|代价|频繁接触会导致人界意识体“地界化”——情绪不稳、记忆混乱、现实感丧失|
|白月离的特殊性|	她作为“空白谱系”，梦境通道对她双向开放——她既能进入地界，也能将地界意识体聚焦成可交流形态|

2. 共鸣裂缝

|维度|规则|
|---|---|
|触发|茜塔莉娅的共鸣本能 + 强烈情感振动源|
|表现|帷幕局部撕裂，地界意识体被吸引，试图穿透|
|限制|裂缝只能维持极短时间，且位置不可控|
|代价|茜塔莉娅弥散加速，白月离精神疲惫，地界意识体可能趁机逃逸|
|叙事功能|	每次共鸣都是一次“地界泄漏”事件，推动剧情|

3. 命名仪式

|维度|规则|
|---|---|
|触发|天界意识体或人界代行者对地界意识体进行命名|
|表现|地界意识体获得模糊自我意识，开始进化|
|限制|命名必须精确，否则会产生“畸变体”|
|代价|命名者与被命名者建立连接，地界意识体的痛苦会反噬命名者|
|叙事功能|	这是天界控制地界的主要手段，也是地界觉醒的主要途径|

4. 遗忘坠入

|维度|规则|
|---|---|
|触发|人界集体遗忘某事物、概念、记忆
|表现|该事物坠入地界，成为地界意识体的养料
|限制|坠入不可逆，除非有人重新命名并持续记忆
|代价|被遗忘之物在地界积累，形成“暗流”，最终可能反扑人界
|叙事功能|卡斯德莫作为艺术之都，遗忘速度极快，地界暗流异常危险
