# 维斯塔

维斯塔(Vesta)是天界“边界—依附”双重本能的耦合体。人界把她理解为“纯洁之神”或“仪式与圣所之神”，但这个称号只描述了她的一个面向。

- **人界称号**：纯洁与仪式之神
- **本能核心**：边界必须维持；更高结构必须依附。
- **存在方式**：她不是“选择”保持纯洁，而是无法与混乱、粗糙、低俗共存；她也不是“选择”服从，而是无法停止依附于更高的结构。她是天界仪式的化身，维持神明与信仰网络之间的接口，确保天界干预人界时“不被污染”。
- **双重本能的张力**：边界本能要求她排斥异质，依附本能要求她服从更高结构。当更高结构本身开始与“不洁”妥协时，两个本能会把她撕开。
- **行为逻辑**：
  - 识别不洁 → 本能排斥，无法靠近。
  - 识别更高权威 → 本能服从，无法质疑。
  - 当权威被玷污 → 本能崩溃，或本能地净化权威。
  - 当自己被玷污 → 本能自我隔离，甚至自我毁灭。
- **冲突点**：
  - 与茜塔莉娅：茜塔莉娅的共鸣不筛选，接纳痛苦、肮脏、混乱；维斯塔本能地排斥这种“不洁的共鸣”。一个要求纯粹，一个要求包容。
  - 与哈拉利：她本能地依附哈拉利，视他为神圣结构的顶点；但当哈拉利为了结构稳定而与地界妥协时，她的虔诚与高雅发生冲突。
  - 与地界：地界是“未命名/不洁”的沉积层；她本能地排斥，但依附本能可能要求她服从“净化地界”的命令，甚至与地界意识体接触。
  - 与自身：服从权威可能玷污纯粹；维持纯粹可能违抗权威。她无处可退。
- **叙事功能**：不是反派，而是“神圣的囚徒”。她代表秩序的美与残酷，是天界秩序最纯粹的化身，也是茜塔莉娅最深刻的阻碍。
- **本能困境**：服从 = 可能玷污纯粹；纯粹 = 可能违抗权威。她无法同时满足两个本能。
- **可能的剧情钩子**：哈拉利可能派她去“净化”茜塔莉娅；但她无法理解，净化一个人等于杀死她。
- **命名备注**：Vesta 是人界某一传统的投影名；不同文化对她的称呼不同。正典中应避免把她直接等同于现实宗教的神祇。
- **正典备注**：
  - 不可写成审美偏好或信仰选择；她的排斥与服从都是本能。
  - 不可写成嫉妒、私怨或权力欲。
  - 她的“净化”不是恶意，而是边界本能的延伸；但她的行为确实会造成伤害，正典不得替她开脱。
  - 她与哈拉利的关系不是“忠臣与暴君”，而是“局部系统与更高结构的耦合”；当结构要求牺牲她时，悲剧才成立。
