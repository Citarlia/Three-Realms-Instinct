# 《三界本能》（Three Realms Instinct）（暂定）

### 项目简介

一个开放共创的玄幻世界观创作站。任何对该项目内容感兴趣、并希望提供想法的人，都可以 Fork 本项目进行创作。

### 项目结构
```text
.
├── worldbuilding/        
│   ├── three-realms.md       # 三界设定
│   ├── interaction-laws.md   # 三界交互法则
│   ├── timeline.md           # 纪年表
│   └── glossary.md           # 术语表
├── characters/           
│   └── design-patterns.md    # 新角色设计范式
├── stories/              
│   ├── canon/                # 官方正典
│   │   ├── core/             # 核心正典
│   │   └── extension/        # 扩展正典
│   └── fan/                  # 同人实验
└── writing-principles/
```

### 创作分类

- 正典：官方承认的主线故事。
- 同人实验：自由创作，不纳入官方时间线。

### 创作要求

- 创作内容必须遵守中国大陆出版作品相关法律法规，绝对禁止色情、暴力、政治敏感等任何违规内容。
- 正典创作需按照大纲设计的走向推进。
- 同人实验由创作者自由发挥，但不得与正典内容相冲突，也不能影响正典内容的推进。
- 对该项目所有内容的再创作，均需符合基本人设和世界观。
- 可以使用AI辅助创作，但不可以无脑全部由AI创作。所有AI辅助内容应控制在 **30%** 以下

### 合并要求

所有合并请求暂时由本项目所有者一人审核，符合创作要求并通过审核后即会合并 PR。

**当前大力推荐以下内容**：

- 正典中尚未完成的内容；
- 有利于完善世界观或人物形象的同人故事；
- 额外的世界观补充。

如果提交内容与已有内容存在冲突，本项目所有者会公平核对，并保留更优秀的版本。

### 创作激励

对于优秀贡献者，本项目所有者会不定期赠送相关周边等。待项目规模逐渐扩大后，还可能举办相关征文比赛。

### 许可协议

本项目采用 `CC BY-NC-SA 4.0` 协议。你可以自由分享、改编，但必须署名、不得用于商业用途，且衍生作品必须以相同协议共享。具体内容请参考 LICIENSE。

### 参与方式

欢迎通过 Issue 讨论，或通过 Pull Request 提交设定、同人创作与正典扩展。
