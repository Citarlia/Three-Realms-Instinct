# 《三界本能》（Three Realms Instinct）（暂定）

### 项目简介

一个开放共创的玄幻世界观创作站。任何对该项目内容感兴趣、并希望提供想法的人，都可以 Fork 本项目进行创作。

**一句话世界观**：天界是意义与概念层，人界是物质层，地界是本能与潜意识层。所有存在皆出于本能行动，没有绝对正反派；冲突来自本能之间的结构性碰撞。

### 创作分类

- **核心正典**：官方承认的主线故事与不可更改的设定（三界本体论、无反派原则、主要人物的本能核心）。由项目所有者保留最终解释权。
- **扩展正典**：社区提交、审核通过的新神明、新地区、新历史事件、新角色。与核心正典不冲突。
- **同人实验**：自由创作，不纳入官方时间线。可以与正典冲突，但必须标注为非正典，不得冒充官方内容。

### 创作要求

- 创作内容必须遵守中国大陆出版作品相关法律法规，禁止色情、政治敏感等违规内容。涉及暴力时，不美化、不宣扬过度血腥暴力；允许主题性、暗示性、悲剧性描写。
- 正典创作需按照 `content/stories/canon/outline.md` 的走向推进。
- 同人实验由创作者自由发挥，但不得冒充正典内容，也不能影响正典内容的推进。
- 对该项目所有内容的再创作，均需符合基本人设和世界观。
- 可以使用 AI 辅助创作，但需在提交时披露使用范围（头脑风暴、翻译、校对、正文等）。核心正文应由人类作者完成；AI 不得用于伪造设定来源或冒充他人创作。

### 合并要求

所有合并请求暂时由本项目所有者一人审核，符合创作要求并通过审核后即会合并 PR。

**当前大力推荐以下内容**：

- 正典中尚未完成的内容（见 `content/stories/canon/outline.md` 与各“待补”文件）；
- 有利于完善世界观或人物形象的同人故事；
- 额外的世界观补充。

如果提交内容与已有内容存在冲突，本项目所有者会公平核对，并保留更优秀的版本。核心正典中的事实性冲突以最新合并版本为准；扩展正典可以保留“替代解释”，但需标注为替代方案。

### 创作激励

对于优秀贡献者，本项目所有者会不定期赠送相关周边等。待项目规模逐渐扩大后，还可能举办相关征文比赛。
