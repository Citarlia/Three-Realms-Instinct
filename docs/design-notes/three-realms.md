# 三界设定的设计笔记

> 本文件是作者向的设计说明，不是设定正文。设定正文见 `content/worldbuilding/three-realms.md`。

## 建议写法

- 天、人、地三界并立，但不是三个国家，也不是善恶阵营，不是简单的上下层，而是不同概念的不同存在形式。
- 天界是意义 / 概念 / 信息层；人界是物质 / 能量层；地界是本能 / 潜意识 / 集体无意识层。
- 三界都有自己的语言与意识形态，但天界通过“概念操作技术”维持三界结构稳定。
- 所有存在皆出于本能行动，没有绝对的正反派。冲突来自本能之间的结构性碰撞，而非善恶对立。

## 核心要点

- 三界是分层本体论，不是上下楼。
- 天界管“意义”，人界管“物质”，地界管“本能”。
- 无绝对正反派，恶是本能碰撞的副作用。
- 天界并非“统治三界”，而是维持结构稳定。

## 应该避免

- 天界是披着神皮的官僚体系。
- 试图用科学解释魔法。
- 地界是绝对的恶，天界是绝对的善。
- 用“上界 / 下界”的空间想象替代层级关系。

## 术语分层

同一个东西在不同视角里有不同名字。正文应尽量标明是哪一层在说话：

| 天界自称 | 人界投影名 | 作者用词 |
|---|---|---|
| 结构收敛点 | 主神哈拉利 | 结构本能 |
| 共鸣节点 | 音乐与歌剧之神茜塔莉娅 | 共鸣本能 |
| 边界-依附耦合体 | 纯洁与仪式之神维斯塔 | 边界本能 + 依附本能 |
| 接口术 | 神迹 / 魔法 | 概念操作技术 |

- “科技树”是作者向的游戏 / 科幻词，正文不要用；正文用“概念操作技术”或“接口术”。
- “反噬 / 侵蚀 / 污染 / 堕落”自带反派语气。正文要么改成中性的“回涌 / 渗漏 / 耦合 / 混成”，要么明确写成“天界称之为……”。
- “社会”对天界和地界未必成立。天界更像张力矩阵，地界更像生态 / 沉积层；如果要保留“社会”，先定义它在这两界指什么。

## 可选的深化方向

- **三层互为投影**：不要让“信息层”变成新的“真相层”。如果天界是“真的”、人界是“投影”、地界是“残余”，世界仍然在排高低；更彻底的做法是三层互为投影，没有哪一层是本体的。
- **天界没有政府**：天界有“能力”，没有“主权”。哈拉利不“下令”，他只是让结构收敛。人界看到的“神职 / 主神 / 分权”，是人对张力矩阵的官僚化翻译。
- **地界不是“下方”**：地界是同一实在的背面 / 沉积层。用“上下楼”写地界，会把它变成地下室，也会让“结构性排除”退化成“阶级压迫”的熟套。
- **“人界首府”需要定案**：21世纪现实世界没有世界政府。卡斯德莫是自由市、特别文化区、城邦，还是虚构城市？在《卡斯德莫》设定里给出法律地位，否则“首府”会悬空。
- **信仰经济**：如果信仰 / 情感 / 艺术是燃料，就需要回答谁生产、谁消费、谁控制、稀缺时会发生什么。卡斯德莫可以是一座“无意识的燃料农场”。

## 检查清单

- 这个设定是从天界本能推导出来的，还是从人界职业反推的？
- 这个神 / 意识体的“人类投影”是什么？投影的误差在哪里？
- 这段文字有没有把天界的词和人界的词混在一起？
- 有没有把“结构性冲突”写成“善恶对立”？
- 有没有用“科学术语”替玄幻贴金？
- 有没有把地界写成“地下室”或“反派阵营”？
