# 三界交互法则的设计笔记

> 本文件是作者向的设计说明，不是设定正文。设定正文见 `content/worldbuilding/interaction-laws.md`。

## 核心原则

- 三界是分层本体论，不是同一物理空间。
- 交互有接口、有代价、有盲区；没有“万能神力”。
- 不要用科学解释魔法，也不要用“量子 / 信息熵 / 高维”给玄幻贴金。
- 天界改变的是人界对“什么值得注意、什么可能发生”的排序，不是直接改写物理定律。
- 每次干预都要有代价：神明失忆、权柄磨损、代行者折寿、地界回涌。

## 可观测性

- 神迹可以被经历，但不能被重复验证。
- 神迹留下的物理痕迹必须能被解释为自然事件；仪器记录到的异常通常会被解释为误差或巧合。
- 大规模、可重复、无法合理化的物理显化是正典禁忌，不是常规手段。一旦出现，帷幕就会出现结构性裂缝，故事进入“泄漏事件”模式。
- 这条规则是为了同时保住两件事：人界仍然是21世纪现实；神明显现仍然有戏剧冲击。

## 常见坑

- **神明万能**：如果祈祷总能灵验，故事就没有代价。让“概率偏转”只改变偏向，不保证结果。
- **大规模显化**：天兵天将、城市上空的神像、全球直播的神迹，会直接推翻“认知帷幕”。正典中应避免。
- **把“反噬”写成恶意**：地界回涌是结构性压力，不是地界在“报复”。天界可以称之为“反噬”，但作者要知道那只是天界的措辞。
- **把“命名”写成万能钥匙**：命名会建立连接，也会反噬命名者；命名必须精确，失败会产生畸变体。
- **把“遗忘”写成单向删除**：遗忘坠入是不可逆的，但被遗忘之物会在地界积累，形成暗流，最终回涌。
- **把“代行者”写成传声筒**：代行者有自由意志，会误读、背叛、放大或扭曲神意；这是戏剧来源，不是 bug。

## 检查清单

- 这次干预的接口是什么？（梦境 / 仪式 / 代行者 / 艺术作品 / 圣地 / 圣物）
- 这次干预的代价是什么？谁付？
- 这次干预能被科学重复验证吗？如果不能，人界会如何解释它？
- 这次干预有没有撕裂帷幕？裂缝吸引了什么？
- 这段描写是从哪个视角写的？是“神在发力”，还是“人界在解释”？
- 有没有把“概率偏转”写成“许愿机”？
- 有没有让地界看起来像“邪恶势力”？
